# Аудит интерфейса Kisht — 15 ноября 2026

## Область проверки

Текущий локальный проект: адаптивная вёрстка, форма участка, календарь полива,
вкладка рекомендаций, помощник, демонстрационная 3D-сцена и регрессионные тесты.
Это не сертификация агрономической модели и не проверка всех внешних API в реальном времени.

## Исправления

| Проблема | Исправление |
| --- | --- |
| Чат выходил за левую границу мобильного экрана: измерено −7,33 px при ширине viewport 360 px | Размер относительно доступной ширины; на телефоне фиксированы оба отступа по 8 px. Повторное измерение: левый край 8 px |
| Минимальная ширина месяца 280 px превышала внутреннюю ширину вложенных карточек | Минимум календарной сетки ограничен 100% контейнера |
| Часть разделов скрывалась за горизонтальным скроллом меню | На телефоне четыре раздела в сетке 2×2; на планшете отдельная строка навигации |
| Длинные подписи и числа растягивали grid/flex-блоки | Сжимаемые колонки, min-width:0, переносы подписей; таблицы прокручиваются внутри контейнера |
| В календаре отображались дозы вроде 9.947602355715626 mm | Локализованное отображение с одной цифрой после запятой; исходная точность данных сохранена |
| Мобильные элементы карты были тесными | Две колонки кнопок, отдельная строка поиска, высота основных действий 44 px |
| Помощник мог перекрывать конец страницы | Нижний отступ страницы и учёт safe-area панели |
| Активный раздел был обозначен только визуально | Добавлен aria-current |
| seasonLength без явного профиля возвращал длительность пшеницы для других культур | Выбор defaultProfiles по культуре; регрессионные проверки кукурузы и картофеля |

## Проверено

- `npm test`: 72 теста, 72 успешно.
- `npm run build`: TypeScript и production-сборка проходят.
- Браузер: 320, 360, 768, 1440 px; в проверенных состояниях ширина документа равна доступной ширине экрана.
- Календарь на 320 px: внутренняя ширина 208 px, горизонтального переполнения страницы нет.
- Чат на 360 px: обе границы внутри экрана, поле сообщения и отправка доступны.
- Демонстрационная 3D-сцена и карточки риска отображаются; в проверенном сеансе ошибок console.error не обнаружено.

## Осталось проверить отдельно

- iOS/Safari и Android с открытой экранной клавиатурой; высокая контрастность и масштаб 200%.
- Реальные загрузки NASA/SRTM/прогноза, ошибки сети и сценарии частичных данных после развёртывания.
- Производительность 3D на слабом телефоне. Сборка предупреждает о крупном чанке Field (~922 kB до gzip).
- Локальная агрономическая калибровка каждой культуры. Условные сигналы жары/холода/воды не доказывают гибель растений и не являются прогнозом урожая.

Изменения находятся в локальном checkout. Публикация в размещённую версию в рамках этой проверки не выполнялась.
